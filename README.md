## 双 ISP 改变了什么，没改变什么

平台风控查的是 IP 的 ASN 归属。数据中心 IP 的 ASN 挂在 Linode、Vultr 这类 IDC 名下，TikTok 会限流、ChatGPT 会弹"不可用地区"。住宅 IP 的 ASN 挂在民用宽带运营商名下，风控库看到的就是一个普通美国家庭在上网。

双 ISP 是在这一层再加一道：同一个 IP 在两家不同的民用运营商名下都有注册记录。实际作用在于，当某一家 ISP 的整个网段被平台批量标记时，另一家的记录还能撑住。识别为家宽的概率更高，但没有任何方案能保证 100% 不被风控，这是概率问题。

**双 ISP 不等于给你两个 IP。** 四档套餐都是 1 个 IPv4，要更多 IP 得单独加购。这点每年都有人搞错。

SixtyNet 的双 ISP 上游目前出现过两种：Astound Broadband（原名 Wave Broadband）和 Cox Communications。Cox 那段要加钱，走的路由也不一样（联通去程会经过 GTT 再进 Cox）。下单前可以在工单里问一句当前分到哪家。

## 9929 只覆盖回程，去程是另一回事

这是前排文章最容易含糊的地方。有些介绍直接写"三网 AS9929"，实测路由并不是这样。

第三方测评记录的路由是这样的：

- **电信**：去程 CN2 直连洛杉矶，回程 CN2
- **联通**：去程直连联通洛杉矶节点，接 GTT，再接 Cox；回程走 AS10099 + AS9929
- **移动**：去程直连移动洛杉矶节点，回程强制走电信 CN2

也就是说，联通用户能吃到 9929 的只有回程这一段，去程是普通国际互联加 GTT 中转。电信和移动的用户实际用的是 CN2。9929 的价值在于晚高峰回国丢包少、延迟稳，但如果你的痛点在去程，这条线帮不上。

还有一点：**官方屏蔽了 PING**。你拿不到 ICMP 延迟数据，只能靠 TCP 探测或者实际业务体感。买之前指望看 ping 图判断线路质量的人，这里会失望。

## 80 和 443 端口默认关闭

这是 SixtyNet 住宅 IP 系列最该提前知道的限制，比价格更容易踩坑。

80 和 443 在这条产品线上不可用。原因写在产品逻辑里：这两个端口对外提供服务，容易让整个 IP 段被扫描、被滥用，进而影响同段其他用户的 IP 属性。它卖的就是 IP 干净，所以把最容易招黑的两个端口关了。

后果很直接：不能拿它跑公开网站、不能直接挂 HTTPS 服务。需要对外提供访问的，走 `forward.sixtynet.net` 配端口转发和白名单，把流量导到非标准端口。真要建站，SixtyNet 自己的 LAX 系列才是对的选项，那些套餐有独立的 CN2 GIA 线路和高防，端口不受限。

反过来说，如果你买它就是为了让 TikTok、Claude、亚马逊后台看到一个美国家庭 IP，端口限制对你没有任何影响。
